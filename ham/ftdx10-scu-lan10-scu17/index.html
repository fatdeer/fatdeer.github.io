FTDX10、SCU-LAN10 与 SCU-17 配合使用

这三台设备可以按用途规划两条路径：SCU-LAN10 负责网络远程控制，SCU-17 为台站电脑提供 CAT 和音频接口，FTDX10 完成收发。

下面是依据各设备接口功能设计的组合接法与调试方案，尚未对三者同时连接进行实机验证。物理连接可以分开，电台的频率、模式、音频源和发射状态仍由两条路径共同影响，因此应明确当前由哪个软件操作。

一、设备分工

设备 在本方案中的任务 放置位置
FTDX10 电台收发、模式和音频源选择 台站
SCU-LAN10 通过 LAN / Internet 提供远程操作、音频和频谱 台站
SCU-17 为电脑提供串口 CAT、模拟音频及 PTT/FSK 接口 台站电脑旁
台站电脑 运行 N1MM+、数字模式软件；需要时接受远程桌面操作 台站
远程电脑 运行 Yaesu 远程软件，或远程操作台站电脑 操作员所在地

SCU-17 不是网络设备。把它接在远程电脑上，不会自动跨互联网连接台站的电台。

二、连接规划

flowchart TD
    R["远程电脑"] -->|"网络远程软件"| L["SCU-LAN10"]
    L <-->|"USB 与 ACC"| T["FTDX10"]
    R -->|"远程桌面"| P["台站电脑"]
    P <-->|"USB"| S["SCU-17"]
    S <-->|"RS-232C 与 RTTY/DATA"| T

图中是两条操作路径；远程桌面服务须单独部署，不由 SCU-LAN10 或 SCU-17 提供。

连接 实施要点
SCU-LAN10 ↔ FTDX10 ACC 使用设备配套的 ACC 连接线
SCU-LAN10 ↔ FTDX10 USB 使用配套 USB 线
SCU-LAN10 ↔ 台站网络 Ethernet 接入，先完成局域网配置
SCU-17 ↔ 台站电脑 USB 连接，先安装对应驱动
SCU-17 CAT/RS-232C ↔ FTDX10 RS-232C 使用符合手册要求的直通串口线
SCU-17 DATA ↔ FTDX10 RTTY/DATA 核对两端引脚后使用匹配的音频/PTT 数据线

SCU-LAN10 的标准接法同时使用电台 USB 和 ACC。不能用无源 USB 分线线让 SCU-LAN10 和电脑同时作为同一个电台 USB 设备的主机。SCU-17 走电台 RS-232C 与 RTTY/DATA，是本方案为台站电脑规划的独立接口路径。

不要把 SCU-LAN10 机身上的 RS-232C 接口当作 FTDX10 的 CAT 转接口；其安装手册注明，该接口不用于 FTDX10 的标准连接。

三、先识别 SCU-17 的电脑设备

连接 SCU-17 后，在台站电脑上确认其 Enhanced、Standard 串口以及 USB Audio CODEC 音频设备。

设备 用途
SCU-17 Enhanced COM 经 SCU-17 的 RS-232C 连接电台 CAT
SCU-17 Standard COM PTT / FSK 控制，按接口实际映射配置
SCU-17 USB Audio CODEC 接收音频输入、发射音频输出

若电脑还连接其他 Yaesu 设备，仅靠“Enhanced / Standard”名称容易混淆。可单独拔插 SCU-17，记录随之出现和消失的设备，再在软件中选择。

SCU-17 的默认映射是 RTS=PTT、DTR=FSK。 内部配置可能改变映射，应按实际设备确认。此前 FTDX10 直连 USB 的 Standard DTR=CW 示例使用的是电台自身的 USB 键控能力，不能直接复制到 SCU-17。

需要 N1MM+ 发送 CW 时，应另行规划连接电台 KEY 接口的键控器或经确认适用的键控电路，并单独测试。FSK 输出不应被直接当作已接通的 CW 点划输出。

四、区分 USB CAT 与 RS-232C CAT

FTDX10 的 USB CAT 和物理 RS-232C 使用不同菜单参数。

路径 电台侧参数 电脑侧配置
SCU-LAN10 → 电台 USB CAT RATE、CAT TIME OUT TIMER、CAT RTS 由 SCU-LAN10 安装流程配置
SCU-17 → 电台 RS-232C 232C RATE、232C TIME OUT TIMER 软件选择 SCU-17 Enhanced，串口参数匹配电台

SCU-LAN10 的 FTDX10 安装说明使用 USB CAT 38400 bps、超时 10 ms、CAT RTS=ON；N1MM+ 的电台直连 USB 指南则建议 CAT 超时 1000 ms 或更高。两种用途应分别记录配置，不能不加区分地套用同一篇教程。

对于 SCU-17 路径，可从 232C RATE=38400 开始，使软件速率一致；停止位、握手和超时参数按电台 CAT 文档及实际测试核对。不要为了修改物理串口而误改正在服务 SCU-LAN10 的 USB CAT 参数。

五、按工作场景选择音频源

SCU-LAN10 的远程发射使用电台 USB 音频；SCU-17 通过数据线把模拟音频送到 RTTY/DATA。电台必须选择当前需要的输入。

场景 发射音频路径 配置重点
Yaesu 远程软件进行 SSB SCU-LAN10 → 电台 USB SSB MOD SOURCE=REAR，REAR SELECT=USB
台站电脑进行 DATA 音频模式 SCU-17 → RTTY/DATA 当前 DATA 模式选择 REAR 音频，REAR SELECT=DATA
台站电脑通过 SCU-17 进行 SSB 音频发送 SCU-17 → RTTY/DATA 当前 SSB 模式选择 REAR，REAR SELECT=DATA；单独核实电平与 PTT
本机话筒通联 电台话筒输入 恢复当前模式的话筒源设置

SCU-17 音频软件应选择它自己的 USB Audio CODEC。先调接收，再从较低发射音频电平调试，观察电台实际功率和 ALC。

使用 SCU-17 的硬件 PTT 时，软件控制的是 SCU-17 的 RTS 输出，继而通过线缆控制电台 DATA PTT 脚；它不是电台内置 USB 虚拟串口的 RTS。电台端应选择适用模式的后部 DATA PTT 路径，而不是误选内置 USB RTS。也可以单独采用 CAT PTT，但不要同时叠加另一条未经验证的 PTT 路径。

切换工作场景后若出现“进入发射却无调制”，优先检查音频源是否还停留在 USB 或 DATA 的另一侧。

六、远程数字模式与比赛软件怎样配合

先让台站电脑上的 N1MM+ 或数字模式软件通过 SCU-17 在本地正常运行，再通过远程桌面操作这台电脑。解码和发射音频留在台站侧，远程电脑只操作桌面。

Yaesu 的 SCU-LAN10 安装手册对网络音频用于 FT8、AFSK 等模式列出限制，因此本文没有把“转发 SCU-LAN10 的音频”当作已验证的数字模式方案。网络延迟也不适合直接保证比赛 CW 的实时键控体验。

SCU-LAN10 可以作为另一种远程观察或操作路径，但运行台站软件时，应明确控制权。一个程序切换频率或模式后，另一个程序可能立即改回；两个端口没有占用冲突，也不等于没有电台状态冲突。

七、推荐调试顺序

  1. 关机接线，单独验证 SCU-LAN10 的局域网控制、音频和频谱。
  2. 结束其远程操作，再验证 SCU-17 的 CAT 和接收音频。
  3. 选择 SCU-17 所需的电台音频源，低功率测试一种 PTT 方式与发射音频。
  4. 若运行 N1MM+ CW，先确认独立 CW 键控线路，再测试短消息和 Esc 中断。
  5. 保存两套场景的菜单记录，测试切换后是否仍能正常收发。
  6. 最后启用远程桌面或公网中继，验证断开连接后电台能恢复接收。

组合接法应按这些步骤验证，不宜同时启动所有程序后再逐项查错。

现象 优先检查
SCU-LAN10 失去连接 电台 USB / ACC、网络、USB CAT 菜单是否被改动
SCU-17 CAT 不工作 电台物理 RS-232C、直通线、232C 参数、Enhanced 端口
SCU-17 没有接收音频 DATA 接线、USB Audio CODEC 选择、RX 电平
PTT 有效但没有调制 当前模式 REAR SELECT 是否与 USB / DATA 路径匹配
N1MM+ 没有 CW 点划 是否误将 SCU-17 的 FSK 映射当成电台内置 USB CW
频率或模式反复变化 两个软件是否同时写入 CAT 状态
远程电脑找不到 SCU-17 串口 它连接在台站电脑；应操作台站电脑上的软件

八、与 FRP 方案的关系

SCU-LAN10 的 FRP 配置只转发 SCU-LAN10 的四路 UDP 业务。它不会自动转发 SCU-17 的 COM 串口、USB Audio CODEC，也不提供远程桌面。

公网中继与设备组合接法可分开调试；涉及服务器、设备地址及认证凭据时，文章和共享截图均使用占位符。
