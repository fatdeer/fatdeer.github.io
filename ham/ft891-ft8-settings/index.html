FT-891 的 FT8 设置：电台菜单、声卡连接与 WSJT-X 调试

 2026.9.30  HAM

FT-891 的 FT8 设置

FT-891 进行 FT8 通联时，需要同时配置电台的数据模式、电脑的音频输入输出以及收发控制。本文以参考图中的 DATA / OTHERS、后部音频输入、DAKY 控制方案为起点，结合 Yaesu 手册说明设置含义，并给出 WSJT-X 的调试顺序。

一、先接好音频与控制线

FT-891 的 USB 连接用于电脑控制，不能替代音频连接。Yaesu 的数据通信接线图将 USB 和音频线路分别连接，因此需要外部声卡或数据接口把电脑音频接到电台后部的 RTTY/DATA 接口。

信号方向 连接用途
电脑声卡输出 → 电台 DATA IN 把 FT8 发射音频送入电台
电台接收音频输出 → 电脑声卡输入 把接收信号送入软件解码
电脑 → 电台 USB CAT 频率与模式控制
数据接口 → 电台 DAKY 使用图示 DAKY 方案时控制收发

接线应按接口设备说明书完成。电台 USB 驱动提供的串口和外部声卡是两类设备：串口连接成功，并不代表音频也已接通。

二、电台菜单设置表

先将电台工作模式切换为 DATA，再设置以下菜单。长按 F 进入菜单，使用 MULTI 选择项目、修改并保存。

下表保留参考图中的配置值；默认值按 Yaesu 手册核对。

菜单编号 菜单名称 本文参考设置 手册默认值 作用与注意事项
08-01 DATA MODE OTHERS PSK 使用其他数据模式的配置项
08-03 OTHER DISP 1500 Hz（图示值） 0 Hz DATA 模式的显示频率偏移
08-04 OTHER SHIFT 1500 Hz（图示值） 0 Hz DATA 模式的载波点设置
08-05 DATA LCUT FREQ OFF 300 Hz 关闭数据音频低切滤波
08-07 DATA HCUT FREQ OFF 3000 Hz 关闭数据音频高切滤波
08-09 DATA IN SELECT REAR REAR 从后部 RTTY/DATA 接口输入发射音频
08-10 DATA PTT SELECT DAKY（按接线选择） DAKY 通过后部接口的 DAKY 控制收发
08-11 DATA OUT LEVEL 50（起点） 50 数据音频输出电平，供接收电平调试
08-12 DATA BFO USB LSB 使用上边带，符合 FT8 软件的工作方式

参考图中有两处需要修正：08-07 的名称是 DATA HCUT FREQ；08-09 的手册默认值为 REAR，图中标作 MIC。

频率偏移与滤波

OTHER DISP 和 OTHER SHIFT 分别控制显示偏移和载波点，并不是 WSJT-X 瀑布图中的发射音频位置。表中的 1500 Hz 是图示方案，不能把它当作所有接线与软件组合的固定要求。应用后应核对电台显示、软件读回频率和实际收发位置，避免再在软件中重复补偿同一偏移。

把低切、高切设为 OFF，只是关闭这两项音频滤波；不意味着整条接收链路必然具有平坦的 0–3000 Hz 通带。还应检查电台的接收带宽、SHIFT 等设置，观察瀑布图两端是否明显衰减。

PTT 必须与接口一致

DAKY 指后部 RTTY/DATA 接口的 PTT 控制脚。若接口没有连接并驱动这条线，仅设置 DAKY 不会自动让电台发射。

手册还提供 RTS、DTR 两种 USB 虚拟串口控制方式。采用哪种方式，就让接口、电台菜单和软件设置配合哪种方式。软件使用 CAT 命令发射时，也应通过 Test PTT 实际确认，不要将 CAT、RTS/DTR 和 DAKY 视为同一条控制路径。

三、WSJT-X 设置

在软件的设置窗口中依次检查以下项目。

设置位置 配置要点
General 填写自己的呼号和网格
Radio → Rig 选择 Yaesu FT-891
Radio → Serial Port 选择实际连接电台的 CAT 串口，参数与电台一致
Radio → PTT Method 按实际接口选择 CAT、RTS、DTR 或接口支持的 VOX 方案
Radio → Mode DATA 接线优先试 Data/Pkt，确认电台仍为 DATA 且 DATA BFO 为 USB
Radio → Split Operation 可试 Fake It；以 CAT 和实际收发测试结果为准
Audio → Input / Output 选择连接电台的外部声卡，不要误选电脑内置麦克风或扬声器

若软件模式切换不符合预期，可手动保持电台 DATA 模式，并将软件的 Mode 设为 None。这里的 None 表示软件不改电台模式，并非关闭 FT8。

WSJT-X 的分频功能用于把发射音频保持在合适的通带内。使用 Fake It 后，电台在收发切换时改变显示频率可能是正常行为，应结合软件的分频状态判断。

四、按顺序调试

  1. 同步电脑时间。 确认系统自动校时正常，再进行 FT8 解码和通联。
  2. 测试 CAT。 点击 Test CAT，确认成功，并检查软件能否正确读写电台频率。
  3. 测试接收。 打开 Monitor，检查瀑布图和解码；逐步调整声卡输入及 DATA OUT LEVEL，避免输入过载。
  4. 测试 PTT。 先降低射频功率，在适当的测试负载或已匹配天线上短暂执行 Test PTT，再恢复接收。
  5. 调整发射音频。 由低音频电平开始短暂使用 Tune，观察输出功率和 ALC；以稳定输出、不过度驱动为目标，避免靠加大音量追求功率。DATA OUT LEVEL 不是发射功率设置。
  6. 进行通联。 确认 FT8 模式、上下边带及收发周期正确，先完成一次完整 QSO，再决定是否提高功率。

五、常见问题

现象 优先检查
CAT 成功，瀑布图无信号 外部声卡、接收音频线、软件 Input 选择
有信号但无法解码 电脑时间、DATA BFO 是否为 USB、接收是否过载
电台进入发射但没有射频输出 声卡 Output、发射音频线、08-09 是否为 REAR
电台无法进入发射 软件 PTT 方式与 DAKY / RTS / DTR 接线是否匹配
显示频率或收发位置异常 OTHER DISP、OTHER SHIFT，以及软件的分频或额外偏移
瀑布图边缘信号明显较弱 DATA 低切、高切、接收带宽与 SHIFT
输出不稳定或 ALC 明显升高 发射音频是否过大，接口电平及射频功率设置
