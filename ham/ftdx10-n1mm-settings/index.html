FTDX10 配置 N1MM Logger+：双串口、CW 键控与 PTT

 2026.9.30  HAM

FTDX10 配置 N1MM Logger+

FTDX10 通过 USB 连接电脑后提供两个虚拟串口：Enhanced 用于 CAT，Standard 用于发射控制。本文逐项记录参考图中的设置，并说明与官方推荐配置的差异，便于搭建单电台 CW 比赛环境。

一、驱动和端口识别

先安装 Yaesu 提供的虚拟 COM 驱动，再连接电台后部 USB 与电脑。在 Windows 设备管理器的“端口（COM 和 LPT）”中查看两个 Silicon Labs Dual CP2105 端口。

设备类型 参考图中的端口 用途
Enhanced COM Port COM5 CAT：频率与模式控制
Standard COM Port COM10 CW 键控与 PTT 等发射控制

COM5、COM10 只是这台电脑的编号，应按自己的设备管理器替换。图中的其他 COM3、COM4、COM6–COM9 是蓝牙串口，不用于本例。

二、Hardware 页面

打开 N1MM+ 的 Config → Configure Ports, Mode Control, Audio, Other…，选择 Hardware。图中采用 SO1V，即单操作员、一个 VFO 的配置。

项目 Enhanced 行（图中 COM5） Standard 行（图中 COM10）
Radio FTDX10 None
Digi 不勾选 不勾选
CW/Other 图中未勾选 勾选
IP Addr:Port 留空 留空
Details 点击 Set 配置 CAT 点击 Set 配置 CW/PTT

其余未使用的串口保持 None，LPT1–LPT3 的 CW/Other 不勾选。Standard 行的 Radio 设为 None，是因为它不承担 CAT；并不表示这个端口未使用。

三、图中的 COM5 设置

设置项 图示值
Speed 38400
Parity N
Data Bits 8
Stop Bits 1
DTR（pin 4） CW
RTS（pin 7） Always On
Radio Nr 1
PTT Delay 30 ms
Radio Polling Rate Normal
Enable Both Hardware & Software PTT 勾选
PTT via Radio Command CW Mode 勾选
PTT via Radio Command SSB Mode 不勾选
PTT via Radio Command Digital Mode 不勾选
Rig Blaster Interrupt 不勾选
Digi Mode: Do not reset radio codec 不勾选
FootSwitch（pin 6） None

图中的 CAT 端口摘要为 38400,N,8,1,DTR=CW,RTS=Always On,Tx=1。

这里需要区分图示记录与推荐起点。 图中窗口底部的 Suggested FTDX10 Settings，以及 N1MM+ 官方 FTDX10 条目，均给出：

38400, N, 8, 2, Handshake, Handshake

这意味着图中实际选择的是 1 个停止位、DTR=CW、RTS=Always On，而建议值是 2 个停止位、DTR/RTS 均为 Handshake。新配置优先以官方建议建立 CAT，再按需要调试；不要把两套参数拼成一套。

Enhanced 行未勾选 CW/Other，而真正的 CW 控制在 Standard 行。因此，COM5 对话框显示 DTR=CW，并不能证明 Enhanced 端口承担了 CW 键控。

四、图中的 COM10 设置

设置项 图示值
DTR（pin 4） CW
RTS（pin 7） PTT
VFO Nr 1
PTT Delay 30 ms
Rig Blaster Interrupt 不勾选
WinKey 不勾选
Two Radio Protocol None
FootSwitch（pin 6） None

图中的摘要为 DTR=CW,RTS=PTT,Tx=1。这里的 DTR/RTS 是 USB 虚拟串口控制信号，无需为这些界面标签另外接一条 DB9 线。

五、电台侧配合

电台菜单 配置要点
OPERATION SETTING → GENERAL → CAT RATE 38400，与 N1MM+ 一致
CAT TIME OUT TIMER 1000 ms 或更高；可选 1000 或 3000 ms
CAT RTS 使用官方握手配置时保持 ON
CW SETTING → MODE CW → PC KEYING 图示使用 Standard DTR 键控时选择 DTR

PC KEYING 默认为 OFF；仅把软件 DTR 设为 CW，而未启用电台 PC KEYING，会导致频率控制正常但不能发送点划。

图中的软件 PTT Delay=30 ms，与电台 QSK DELAY TIME 是不同项目，不能相互替代。

六、先明确 PTT 路径，再发送 CW

图中同时勾选了 Enable Both Hardware & Software PTT 和 PTT via Radio Command CW Mode，又将 Standard 的 RTS 设为 PTT。这是同时允许 CAT 与硬件线控制 PTT 的配置记录。

N1MM+ 官方建议选择一种 CW 键控方式和一种 PTT 方式。双 PTT 可能造成收发冲突，因此建议分开测试：

  • CAT PTT 起点： 保留 CW 模式的 PTT via Radio Command，取消 Enable Both Hardware & Software PTT；Standard 保留 DTR=CW，将 RTS 改为 Always Off。
  • 硬件 PTT 测试： 若需要 Standard RTS=PTT，先取消 CW 模式的 PTT via Radio Command，单独确认电台能进入并退出发射。图中没有提供电台侧完整的 RTS/PTT 配置，不能仅凭截图保证这一路径在所有模式下可用。

保留图示双 PTT 方案时，应确认发送结束与中断后均能恢复接收。图中的 30 ms 不是所有外部功放都适用的延迟，也不能据此认定 CAT PTT 具有同样的提前量。

七、验证与排查

  1. 关闭占用同一串口的其他软件，保存 Hardware 配置。
  2. 先检查 CAT：转动电台调谐旋钮，确认 N1MM+ 的频率、模式同步。
  3. 低功率、适当负载下测试一条短 CW 功能键消息。
  4. 确认点划正常、消息结束后恢复接收，再按 Esc 测试中断。
  5. 重启软件，再次确认端口号与收发状态。
现象 优先检查
频率不更新 是否选 Enhanced、串口占用、CAT 速率及停止位
CAT 正常但没有 CW Standard 的 CW/Other、DTR=CW、电台 PC KEYING=DTR
进入发射却没有点划 PTT 已生效但 CW 键控路径未接通
消息结束后仍在发射 CAT 与硬件 PTT 是否同时控制，RTS 是否保持有效
重连 USB 后失效 设备管理器中的实际 COM 编号是否变化
SSB 或数字模式不能发射 图中的 CAT PTT 只勾选了 CW，其他模式需另行配置
